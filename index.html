01

BILATERAL TELEOPERATION

谐波驱动机械臂的低阻力拖动与双边力反馈

实机闭环

问题定义

谐波减速器的静摩擦与换向迟滞造成启动力大、低速卡顿；补偿不足影响拖动手感，补偿过量又可能引起漂移或振荡。主从同步与接触阻力反馈还会放大这些非理想因素。

我的实现与关键方法

  1. 分别辨识主臂与从臂的重力和摩擦特性，通过电流前馈抵消本体负载与低速阻力。
  2. 实现双边 PD 同步与阻尼调节，在从臂引入单侧扰动观测残差补偿，处理跟踪误差。
  3. 围绕启停、换向和接触工况调试速度死区、滤波与补偿限幅，分析静摩擦、时序和参数之间的耦合。
Gravity / Friction FeedforwardPD + ESOCurrent Control

验证与边界

200 Hz

补偿计算与指令下发频率，非力反馈带宽。

已验证的实机行为

重力平衡、低阻力拖动、主从关节同步及接触阻力反馈。

仅 PD 的静止跟踪误差约 1°–2°；低速静摩擦与换向手感仍需优化。

02

SYSTEM IDENTIFICATION / REAL-TO-SIM

物理参数辨识与学习型执行器残差建模

轨迹回放评估

问题定义

仅依赖 URDF 参数与理想 PD，难以复现真实执行器的摩擦和动态响应；单步拟合误差小，也不代表多步闭环轨迹一致。

我的实现与关键方法

  1. 设计低速双向与多速度匀速采集，分离重力项和正反向摩擦；以 WLS、正则化和静态锚点缓解参数耦合与欠激励。
  2. 构建“显式 PD 基线 + 历史状态驱动神经残差力矩”，将物理先验与学习模型接入 Isaac Lab 执行器接口。
  3. 采用 PPO 多步 rollout 优化关节状态误差，比较关节位置与速度的轨迹一致性，诊断闭环误差累积。
WLS / RegularizationResidual TorqueMulti-step Rollout

03

CONTACT-RICH / NON-PREHENSILE MANIPULATION

双臂箱体重定向中的接触协同与稳定释放

仿真策略研究

问题定义

箱体翻到目标角度并不等于任务完成。策略可能依赖桌面摩擦绕过双臂支撑，或在撤离时失稳；接触切换、落桌与释放需要分别建模和验收。

我的实现与关键方法

  1. 在 Isaac Lab 构建双臂推顶、支撑与翻转任务，以 PPO 和 30°→50°→90° 阶段式课程组织策略训练。
  2. 设计接触与几何约束、撤离门控和终止条件，针对“角度达标但仍有残余接触”等失败模式调整奖励。
  3. 分别评估角度误差、落桌稳定性、末端间隙与接触释放；继续验证摩擦、尺寸和初始位姿随机化下的鲁棒性。
Isaac Lab / RSL-RLPPO / CurriculumContact Constraints

验证与边界

1024

训练配置：Isaac Lab 并行仿真环境数。

任务验收分解

  • 目标姿态与稳定落桌
  • 接触释放与双臂撤离
  • 随机化工况与失败分布
